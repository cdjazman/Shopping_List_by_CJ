# Contributing

Thank you for contributing to Shopping List by CJ.

## Development Workflow

- Create a feature branch.
- Make one logical change.
- Test thoroughly.
- Commit.
- Open a pull request.

## Coding Standards

- No inline CSS.
- No inline JavaScript.
- Keep functions small.
- Avoid duplicated code.
- Preserve backwards compatibility.

## Git Commit Style

Use clear commit prefixes such as:

- feat:
- fix:
- refactor:
- docs:
- style:
- test:

## Pull Requests

Every pull request must include:

- What changed
- Why it changed
- Testing performed
- Screenshots if UI changed

## AI Contributors

AI assistants must:

- Read PROJECT.md first.
- Read DECISIONS.md.
- Read ARCHITECTURE.md.
- Preserve existing behaviour.
- Never populate defaults.js.
- Never combine refactoring with new features.
- Stop after each completed task.

## Testing Checklist

Before submitting changes, confirm that:

- App loads
- No console errors
- Local Storage works
- Backup works
- Restore works
- Shop mode works
- Settings work
- PWA installs
